
# Skellify — EdTech & IT Services Platform

Skellify is a dual-purpose digital platform that offers **technology education for students** and **software & IT services for businesses**.  
It acts as a bridge between learning and real-world technology by providing structured courses, industry-oriented training, and professional IT solutions.

---

## 🚀 What Skellify Offers

### For Students
- Foundation Course in Programming & Web Development  
- One Month On-Job Training (OJT) in:
  - Web Development  
  - Automation Testing  
  - Android Development  
- Online classes with structured curriculum
- Assignments, mini-projects, and certificates

### For Businesses
- Web Application Development
- Mobile Application Development
- Automation & QA Solutions
- System Maintenance & Support
- Custom software solutions with project quotations

---

## 🛠️ Technology Stack

The platform is built using a modern and scalable technology stack:

- **Next.js (App Router)** — Frontend framework
- **TypeScript** — Type-safe development
- **Tailwind CSS** — Utility-first UI styling
- **Framer Motion** — UI animations
- **Lucide Icons** — Icon library
- **pnpm** — Package manager

## ⚙️ Setup & Installation

### 1. Clone the Repository

```bash
git clone <repository_url>
cd skellify25
````

### 2. Install Dependencies

```bash
pnpm install
```

### 3. Run Development Server

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 📦 Available Scripts

| Command      | Description              |
| ------------ | ------------------------ |
| `pnpm dev`   | Start development server |
| `pnpm build` | Build for production     |

| `pnpm lint`  | Run lint checks          |
